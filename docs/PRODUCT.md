# AgentHub 产品文档

## 产品概述

AgentHub 是一个多 Agent 协作平台，用户可以与多个 AI Agent 同时对话，让 Agent 之间相互协作完成复杂任务。

## 核心场景

### 1. 单聊模式
与单个 AI Agent 进行一对一对话，适合：
- 单一领域的问答
- 代码编写和调试
- 文档撰写和修改

### 2. 群聊模式（多 Agent 协作）
多个 Agent 同时参与对话，适合：
- 复杂任务分解
- 多领域知识整合
- 并行处理独立子任务

### 3. 主管模式
用户只与主管 Agent 对话，主管负责：
- 分析用户需求
- 将任务分解为子任务
- 委托给合适的子 Agent
- 汇总子 Agent 的结果返回给用户

## 功能列表

### 用户侧功能

| 功能 | 说明 |
|------|------|
| 用户注册/登录 | JWT 认证，支持密码登录 |
| 会话管理 | 创建、删除、置顶、归档会话 |
| 发送消息 | 支持 @mention 触发特定 Agent |
| 实时响应 | SSE 流式输出，边生成边显示 |
| 消息操作 | 回复、重新生成、置顶消息 |
| 上下文管理 | 自动/置顶/排除 三种上下文模式 |

### Agent 侧功能

| 功能 | 说明 |
|------|------|
| Agent 状态显示 | 实时显示 Agent 执行状态（等待/执行中/已完成） |
| 并行执行 | 多个 Agent 同时响应用户消息 |
| 任务委托 | Agent 通过 @mention 委托任务给其他 Agent |
| 主管代理 | 特殊的 Orchestrator Agent，负责协调其他 Agent |

## 用户界面

### 主要页面

1. **登录/注册页**
   - 用户名密码登录
   - 新用户注册

2. **会话列表页（侧边栏）**
   - 会话列表展示
   - 新建会话按钮
   - 会话置顶/归档/删除

3. **聊天主界面**
   - 消息列表
   - 消息输入框
   - Agent 状态指示器
   - Agent 状态侧边栏

### Agent 状态指示器

显示在消息列表上方，实时显示：
- 正在执行的 Agent（蓝色脉冲）
- 等待中的 Agent（灰色）
- 已完成的 Agent（绿色）

### Agent 状态侧边栏

显示在聊天右侧，显示：
- 所有参与会话的 Agent
- 各自的执行状态
- 当前任务内容
- 统计数据（活跃/完成/等待数量）

## 使用流程

### 创建一个多 Agent 会话

1. 点击侧边栏「新建会话」按钮
2. 选择「群聊」模式
3. 选择要参与的 Agent（可多选）
4. 设置会话标题
5. 开始对话

### 使用 @mention

在消息中输入 `@Agent名称` 可以：
- 触发特定的 Agent 回复
- 其他 Agent 不会响应

示例：
```
@BackendAgent 帮我写一个后端接口
```

### 主管 Agent 模式

1. 创建一个包含「主管 Agent」的会话
2. 主管 Agent 会自动识别并接管协调工作
3. 用户只需描述需求，主管会自动分解任务并委托

## 数据安全

- 用户密码使用 BCrypt 加密存储
- 认证使用 JWT Token
- 用户只能访问自己的会话和消息
