# SPEC_PRODUCT_REQUIREMENTS.md

## 概述

本文档是 AgentHub 的产品需求总纲，定义项目目标、用户角色、核心场景和功能优先级。

---

## 项目目标

AgentHub 是一个以 **IM 聊天** 为核心交互范式的**多 Agent 协作平台**。

核心价值：
- 用户可以像使用飞书/微信一样，与不同 AI Agent 单聊或群聊
- 在聊天流中直接查看代码、Diff、网页预览、文件、部署状态等产物
- 支持 @ 多个 Agent 协同工作，Orchestrator 自动拆解任务并分派

---

## 用户角色

| 角色 | 权限 | 典型行为 |
|---|---|---|
| 普通用户 | 使用已有 Agent 对话 | 创建会话、发送消息、查看 Artifact |
| Agent 创建者 | 创建和管理自定义 Agent | 定义 System Prompt、选择模型、配置工具 |
| 系统管理员 | 管理所有用户和 Agent | 运维、监控（可选） |

---

## 核心场景

### 场景 1：用户与单个 Agent 单聊

```
用户 → 新建会话 → 选择 Agent → 发送任务 → Agent 回复（文本/Artifact）
```

用户选择一个 Agent（如 Claude Code），发送任务，Agent 返回文字描述或代码块、文件等 Artifact。

**典型对话：**
- "帮我写一个 React TodoList 组件"
- Agent 返回代码块 + 预览链接

### 场景 2：用户在群聊中 @ 多个 Agent

```
用户 → 新建群聊 → 添加多个 Agent → @Agent1 @Agent2 → 依次回复
```

用户在群聊中 @ 多个 Agent（如 @Claude Code 生成代码，@Codex 检查代码），由 Orchestrator 按顺序分派任务。

**典型对话：**
- "@Claude Code 帮我生成组件，@Codex 检查代码问题"
- Claude Code 先回复，Codex 依次回复

### 场景 3：用户预览 Agent 产物

```
Agent 回复 → Artifact 卡片 → 用户预览 → （可选）应用/部署
```

Agent 返回代码、Diff、网页预览等，用户可在聊天流中直接查看，支持展开全屏、一键复制、应用 Diff。

### 场景 4：用户创建自定义 Agent

```
用户 → 点击创建 Agent → 填写配置 → 保存 → 与该 Agent 新建会话
```

用户定义 Agent 的名称、描述、System Prompt、底层模型，创建一个个性化 Agent。

## 功能优先级

### P0 - 核心闭环（必须完成）

| 功能 | 说明 | 验收标准 |
|---|---|---|
| 会话列表 | 显示用户所有会话，按最近活跃排序 | 能看到历史会话 |
| 新建会话 | 选择 Agent 创建新会话 | 能开始新对话 |
| 单聊模式 | 用户与单个 Agent 1v1 对话 | 能发送消息并收到回复 |
| 消息发送 | 用户消息发送和持久化 | 消息不丢失 |
| 消息历史 | 加载和展示历史消息 | 能翻看历史 |
| Agent 调用 | 后端调用 AI Provider | 能获得 AI 回复 |
| SSE 流式更新 | 服务端推送实时更新 | 消息能流式显示 |
| 代码块渲染 | 前端渲染代码块 | 代码高亮可读 |
| 用户认证 | 注册/登录/JWT | 安全访问 |

### P1 - 协作增强（提升差异化）

| 功能 | 说明 | 验收标准 |
|---|---|---|
| 群聊模式 | 多个 Agent 同会话 | @ 能被解析 |
| @Agent 提及 | 消息中 @Agent | 调度到对应 Agent |
| Orchestrator 调度 | 多 Agent 任务分派 | 依次获得多个回复 |
| Artifact 卡片 | 代码/Diff/预览卡片 | 多类型展示 |
| 上下文连续 | 聊天历史作为 Agent 上下文 | 多轮对话连贯 |
| 用户自建 Agent | 用户创建自定义 Agent | 能创建并使用 |

### P2 - 产品增强（体验优化）

| 功能 | 说明 | 验收标准 |
|---|---|---|
| 会话置顶/归档 | 会话管理增强 | 能整理会话列表 |
| 会话搜索 | 搜索历史消息 | 能找到过去对话 |
| Pin 消息 | 固定关键消息 | 优先进入上下文 |
| 部署状态卡片 | 展示构建/部署进度 | Mock 闭环 |
| Diff 应用 | 一键应用代码变更 | 能将变更落地 |
| 版本历史 | 对话/Artifact 版本 | 能查看历史版本 |

## 非功能需求

### 性能

- 消息响应时间 < 3s（流式首字）
- SSE 连接保持 < 30s 无活动自动断开
- 消息列表分页加载，每次 20 条

### 可靠性

- 消息持久化不丢失
- SSE 断开后自动重连（最多 3 次）
- Agent 调用失败有降级处理

### 安全

- 所有 API 需要 JWT 认证
- 用户只能访问自己的会话
- AI 内容不存储敏感信息
