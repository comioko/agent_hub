# DEMO_SCRIPT.md

## 概述

本文档是 AgentHub 的 3 分钟 Demo 视频剧本，用于答辩演示和功能展示。

---

## Demo 环境准备

### 账号准备

- 测试用户账号：`demo@agenthub.com` / `demo123`
- 预置 Agent：Claude Code、Codex、OpenCode
- 测试会话：2-3 个包含历史消息的会话

### 页面准备

- 打开 AgentHub 首页（已登录状态）
- 打开浏览器开发者工具 → Network → 勾选 "Preserve log"
- 调整窗口大小展示最佳视角

---

## 3 分钟 Demo 流程

### 0:00 - 0:30 | 项目介绍

**画面**：AgentHub 首页 + 会话列表

**台词**：
> "AgentHub 是一个以 IM 聊天为核心交互范式的多 Agent 协作平台。用户可以像使用飞书一样，与不同 AI Agent 单聊或群聊，并在聊天流中直接查看代码、Diff、网页预览等产物。"

**操作**：展示会话列表

---

### 0:30 - 1:00 | 单 Agent 对话

**画面**：新建会话 → 选择 Claude Code → 输入任务

**台词**：
> "首先演示单聊模式。用户新建一个与 Claude Code 的会话。"

**操作**：
1. 点击 "新建会话" 按钮
2. 选择 "Claude Code" Agent
3. 输入：`帮我写一个 React TodoList 组件`

**画面切换**：等待 AI 回复完成

**台词**：
> "Agent 返回了完整的代码块，包含组件逻辑和样式。"

---

### 1:00 - 1:30 | Artifact 卡片展示

**画面**：展示代码块 Artifact 卡片

**操作**：Hover 代码块卡片，显示操作按钮

**台词**：
> "代码块支持语法高亮、复制、全屏预览。用户可以直接复制代码使用。"

**操作**：
1. 点击 "复制" 按钮
2. 点击 "全屏" 按钮展示大图

---

### 1:30 - 2:00 | 多 Agent 协作

**画面**：新建群聊 → @ 多个 Agent

**台词**：
> "接下来演示多 Agent 协作。用户可以在群聊中 @ 多个 Agent。"

**操作**：
1. 新建群聊，添加 Claude Code 和 Codex
2. 输入：`@Claude Code 生成 TodoList 组件，@Codex 检查代码问题`

**画面切换**：等待 Claude Code 回复 → Codex 回复

**台词**：
> "Claude Code 生成了组件，Codex 依次检查了代码质量。这是 Orchestrator 自动调度的结果。"

---

### 2:00 - 2:30 | 用户自建 Agent

**画面**：切换到 "My Agents" 页面

**台词**：
> "平台支持用户自建 Agent。用户可以定义 System Prompt、选择底层模型、配置能力标签。"

**操作**：
1. 点击 "My Agents" 导航
2. 点击 "创建 Agent" 按钮
3. 填写表单（名称、描述、System Prompt）
4. 保存

**画面**：展示创建的 Agent 出现在列表中

---

### 2:30 - 3:00 | 总结

**画面**：展示项目文档结构

**台词**：
> "AgentHub 完整覆盖了 PDF 要求的核心功能：
> - IM 单聊闭环（P0）
> - 多 Agent 协作（P1）
> - Artifact 卡片（P1）
> - 用户自建 Agent（P1）
>
> 文档体系包含 8 个 Spec、11 个 Skill、10 个 Rules，方便后续 AI 辅助开发。"

**操作**：快速展示 docs/ 目录结构

## Demo 检查清单

### 开始前检查

- [ ] 测试账号已登录
- [ ] 预置 Agent 都可用
- [ ] 网络正常
- [ ] 录屏软件已开启
- [ ] 麦克风正常

### 演示中注意

- [ ] 每步操作前停顿 1 秒
- [ ] 语速平稳，不急不慢
- [ ] 关键点配合手势指示
- [ ] 代码块展示时放大字体
- [ ] 出现意外时保持冷静

### 演示后检查

- [ ] 录屏已保存
- [ ] 视频格式正确
- [ ] 时长在 3 分钟左右

## 常见问题应对

| 问题 | 应对 |
|---|---|
| AI 响应慢 | 切到预加载好的历史会话演示 |
| 页面卡顿 | F5 刷新，保持淡定 |
| 网络断开 | 展示录屏备份 |
| 忘记下一步 | 停顿两秒，看台词提示 |
